## Repository privacy rule

This repository must remain safe to publish. See [`docs/PII_POLICY.md`](docs/PII_POLICY.md) and run `scripts/check-pii.sh` before committing. Never commit real names, personal emails, private IPs, personal hostnames/domains, home paths, hardware details, account/tunnel/app IDs, or credentials. The private `agent-memory` store is the only exception and must never be copied into the repo.
